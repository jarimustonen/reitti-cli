# reitti-cli

Agent-first command-line journey planner for Helsinki, Espoo, Vantaa, Kauniainen, Kerava, Kirkkonummi, Sipoo, Siuntio, and Tuusula, powered by Digitransit open data.

**Status:** Private, early development.

`reitti-cli` is intended to let people and AI agents resolve places, compare practical public-transport alternatives, inspect real-time departures and disruptions, and explain a recommended journey through a stable, machine-readable CLI.

The project is independent and is not affiliated with HSL or Digitransit. The command name will be `reitti`.

## Scope

Version 1.0 targets the HSL Journey Planner service area. The design should leave room for other Digitransit routers later without claiming unsupported coverage.

Planning and research live under the [v1.0 epic](issues/v1-0-agent-journey-planner/).
